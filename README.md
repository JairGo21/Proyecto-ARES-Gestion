# Ares

Sistema de gestión de inventario para una tienda, desarrollado como proyecto de Ingeniería de Software I.

## Descripción

Ares busca facilitar la gestión de productos, inventario, ventas, compras y vencimientos, reduciendo errores y pérdidas de mercancía y apoyando la toma de decisiones de compra.

## Objetivos principales

- Gestionar entradas y salidas de inventario.
- Controlar productos próximos a vencer.
- Consultar el historial de ventas.
- Generar y confirmar sugerencias de compra.
- Definir cantidades mínimas de productos.
- Registrar nuevos productos.
- Corregir movimientos registrados por error.

## Usuarios

El sistema contempla principalmente:
1. Administrador de la tienda
2. Esposa del administrador
3. Empleada de la tienda
